# 🔎 Radar de Vagas Tech

Projeto desenvolvido em Python para buscar e filtrar oportunidades de trabalho remoto na área de tecnologia.

## 🚀 Funcionalidades

- Busca vagas nas plataformas Remotive e Remote OK.
- Reúne informações de diferentes fontes.
- Filtra vagas por localização.
- Identifica cargos relacionados à tecnologia.
- Classifica possíveis oportunidades de nível inicial.
- Exibe cargo, empresa, localização, fonte e link da vaga.

## 🛠️ Tecnologias utilizadas

- Python
- Biblioteca Requests
- APIs públicas de vagas
- GitHub Codespaces

## ▶️ Como executar

Instale a dependência:

```bash
pip install requests
```

Execute o programa:

```bash
python main.py
```

## 📁 Estrutura do projeto

- `main.py` — executa a busca e aplica os filtros.
- `fontes.py` — consulta as APIs e padroniza os dados.
- `README.md` — documentação do projeto.

## 📌 Observações

As vagas são obtidas de fontes externas e podem mudar ou deixar de estar disponíveis.

A classificação de nível inicial é baseada em palavras-chave e não garante que a vaga seja adequada para pessoas sem experiência.

## 🎯 Objetivo

Praticar Python, consumo de APIs, manipulação de listas e dicionários, filtros de dados e organização de projetos no GitHub.
